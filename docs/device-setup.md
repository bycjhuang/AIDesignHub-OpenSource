# 本机模型设置与自动配对

## 使用方式

1. 点击左下角常驻「DesignHub 模型设置」，在应用内填写自己的服务地址、模型 ID 和 API Key。
2. 默认启用「保存后自动检测并配对」。内置助手只用软件能力清单规划顺序，随后由本机受控适配器检查已安装程序。
3. 在自动配置面板查看结果。日常返回 Agent 对话选择执行器；高级参数不再作为必填用户流程。

自动规划可能消耗少量内置模型 API 额度。软件清单只有候选 ID、产品、版本、接口、安装与可配对状态，不含启动路径、项目内容或密钥。模型只返回候选排序，不能指定命令、安装程序或扩大权限。内置模型不可用时仍继续固定规则检测与协议配对。

## 正常库、演示库与开发测试

两种模式共用代码，不存在只修改 Demo 的独立前端副本。正常安装的本机模型与配对记录位于应用用户数据的 `device-settings-v1`。项目数据库、任务、文件、成员权限及授权仍留在各自业务库。

旧工作区仅有一份有效模型配置时复制其加密文件，保留原件；不同配置冲突不擅自选用，已清除或损坏的目标配置不从旧库复活。配对记录仅保存已知启动模板的哈希，不存第三方凭据、工作目录、授权 token 或历史模型验证。

指定 `AIDESIGNHUB_DATA_DIR` 的开发启动只使用该根下的共享设备设置，绝不隐式读取真实用户配置。Smoke 也独立隔离；这属于测试安全边界，不代表生产里需要反复设置。

## 自动解决与仍需本人完成的边界

- 自动发现 PATH、官方软件登记、已知应用位置、Python/uv/pipx 和 Hermes 独立安装环境。
- 自动选用支持的 CLI/ACP 入口；检查失败时尝试已发现的兼容候选；不覆盖用户自定义路径、工作目录或 Gateway。
- ACP 成功表示协议握手通过，CLI 成功表示启动帮助检查通过，都不等于模型额度、真实任务或项目成果验收成功。
- ChatGPT/Codex、ZCode 安装可识别，但此版本不接管现有 GUI 会话。外部客户端的登录、MCP 授权仍需本人完成，不绕过确认。
- 不自动安装软件、修改系统 PATH、安全设置或复制第三方密钥。不发送项目任务、联系人消息或创建项目授权。

## 验证

- `npm test`：含配置共享/迁移/隔离、候选验证、失败备用入口与模型输出约束。
- `node scripts/setup-center-app-smoke.cjs`：隐藏 Electron 界面、自动配对替身及派单/验收回归，不使用真实模型。
- `node scripts/agent-setup-smoke.cjs --probe-installed`：显式检查本机已安装 Agent 的启动/协议。临时创建两套独立业务库，验证配对复用，不使用真实项目或调用模型。
