Adaptations made during 2026-10-27 through 2026-10-29 include:

- Hub-local project identity, canvas persistence and native media receipts;
- Hub model configuration and local model gateway instead of cloud credentials;
- Chinese interface text, local branding and navigation integration;
- project style kits, local asset references and generation-state recovery;
- video workflow, local settings handoff and version-source export marks;
- local static-export build and removal of example cloud configuration from
  generated application assets, while keeping upstream server source;
- explicit Apache-2.0 skill licenses and font redistribution notices;
- an elkjs override to a release that explicitly offers GPL-3.0-or-later as
  an alternative to EPL-2.0, with its own licenses and source references retained.
