# AI Hub 技能中心与团队共享

日期：2026-10-27；项目：`D:/AIDesignHUB`。

外层导航的重复“技能中心”入口移除，旧快捷入口转到 AI Hub 内的技能页。旧成员技能、运行评价等业务记录保留，原生技能列表仍从 Agent 的真实注册服务读取，沿用当前对话工作区与技能过滤规则。

## 使用

1. 打开 **AI Hub → 技能中心 → 本机技能**，搜索所需技能，点击“分享到团队”。分享者取工作台当前成员，页面展示身份。
2. **团队共享**显示本机已分享的技能；技能修改后点击“更新分享”，本人可取消分享。分享保存当时的技能说明快照，不自动追踪原目录变化。
3. 要让同事查看，在团队区点击“开启本机共享”，将界面给出的局域网地址与邀请码交给同事。主机应用保持运行。
4. 同事在自己的团队区填写主机地址和邀请码，点击连接，即可搜索和查看该主机的共享技能。远端查看是只读操作；列表定时刷新，也可手动刷新。
5. “停止本机共享”停止局域网访问；“断开连接”只断开本机读取的远端主机。分享记录继续保存在本机。应用重启恢复此前明确开启的共享状态。

没有开启共享服务时，团队区的本机记录尚不能被其他电脑读取。局域网连接受主机在线状态与 Windows 防火墙影响，连接失败会在界面显示，不能据此声称其他电脑已验收。

## 边界

- 分享当前选中的技能说明及名称、用途、分类、分享者和更新时间，不打包本机目录、附件或脚本，不自动安装或执行。依赖其他资源的技能需另外准备资源。
- 本机发布入口重新核验技能注册清单，调用方不能提交文件路径、自定义正文或伪造分享者。详情按文字展示，技能正文中的指令仅是用户查看的资料。
- 独立局域网服务只读共享列表和说明，使用邀请码；不恢复历史项目同步，不开放项目写入、模型配置或 Agent 执行。
- 邀请码只在本机管理界面展示，不进入远端技能列表或模型上下文。连接配置在本机保存，Electron 可用时使用系统加密保护凭据。
- 当前成员身份来自本机工作台，不等同于企业账号认证。远端连接只有读取能力，取消分享仅能在来源主机由原分享身份操作。

关键文件：`backend/team-skill-library.cjs`、`backend/adh-workbench-service.cjs`、`backend/dsh-plugins/adh-skill-library/`、`adh-workbench-ui.js`。
