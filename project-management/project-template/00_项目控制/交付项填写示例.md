# 如何填写一项交付要求

以下是说明，不是已经批准的项目要求；请勿导入为真实成果或进度。

例如：概念设计阶段的“总图与指标一致性复核”。

- 交付项：稳定 ID、阶段 P03、适用分区/专业、负责人、审核人、计划日期。
- 输入：明确的模型版本和指标表版本，以及指标定义/计算口径。
- 输出：项目约定的总图、指标表、复核说明；采用 BIM 时可增加对象参数快照。
- 机械检查：文件存在/可读、导出清单完整、模型和表格引用版本匹配、单位和面积口径明确。
- 专业检查：指标算法与适用依据正确，由具备职责的人或已验证专项引擎执行；有数据不等于已经完成校核。
- 验收证据：审核人、日期、对具体文件哈希/版本作出的决定。
- 失效条件：关联模型/计算口径/项目约束出现新版本时，标记相关检查待复核；历史决定仍保留。
- 不得代推：内部复核通过不等于业主确认、报规批准或款项到账。
