# ADH 内的项目案例研究与成果制作

本轮按用户修正调整产品流程：主导航统一为 AI Hub，当前项目作为其内嵌 ADH Agent 的对话上下文，完成案例筛选、公开检索、阅读、高清图归档、研究写回和 PPT／分析页制作。外部 Agent 接入设置与任务目录位于 AI Hub 左侧的“Agent 协作中心”，旧独立协作页及其输入区不再挂载。

## 用户入口

- ADH 输入框上方不再常驻项目小字和成果按钮。输入 `/` 查看「Hub 项目任务」；`/Hub` 收纳案例选择、调研与成果入口。
- 执行器菜单位于输入框右侧、模型选择器之前。默认「ADH Agent」，原生模型正常可选；外部执行器或多 Agent 协作使用各执行器自己的模型配置，本栏禁用并提示。
- `/协作 @openclaw 第一项任务\n@hermes 第二项任务` 可一次发布不同 Agent 的任务；也可从「多 Agent 协作」编辑多条任务后加入草稿，再点击原生发送。
- 案例页只做链接收集、查看原始资料与图片、多选案例。选中后「交给 ADH」将案例选择及指令交接到 ADH 草稿。没有选中时也可让 ADH 自行按索引挑选。
- `/案例调研` 和 `/案例PPT` 是原生会话命令。案例事实、参考点和逐页方案由 ADH 模型在这次对话中提出；成果生成器只执行 ADH 的方案，不替它做研究。

## 本地文章与原图

案例右侧默认打开「本地原文」，保留正文、图文顺序、图注与表格；「项目原图」查看原始尺寸图片，「项目资料」收纳字段和来源证据。无本地原文的旧案例会在首次打开时后台补档，不调用模型或外部 Agent；已有副本直接离线读取，显式点击「更新本地副本」才重新采集。原始 HTML 独立留存，不执行其脚本。

本地阅读通过 `adh-case://local/<caseId>/index.html` 和受限图片 ID 提供，图片不再全部编码后跨 IPC 传递。协议逐次核对当前项目与案例，iframe 无脚本权限，CSP 禁止外部资源请求。无法获取的图片保留原位占位和原因；补档复用已验证原图，只读取缺失项。有效 GIF 不因缩略图生成失败而丢失。

谷德正文过滤招聘、推荐和广告图。原图优先采用页面声明；仅对谷德 OSS 有媒体标识及标准发布尺寸后缀的图片尝试无尺寸版本，必须经真实读取、格式、尺寸和比例校验，失败时保留发布版本及原因。不是对任意 URL 猜测后即宣称取得原图。

## 多 Agent 协作

一次提交最多 8 项任务，共用原有 Agent 协作中心的 Job／Run。每项有独立执行器、任务内容、状态和结果；稳定请求标识用于并发及持久幂等。预检期间项目、执行器或连接配置变化会拒绝旧派单。一个执行器失败不影响其他任务回传。

进度与最终结果经原生 Session API 和原生可见的 incoming turn-trigger 写入发起对话，不额外请求 ADH 模型。左侧“Agent 协作中心”按 Agent → 项目文件夹 → 任务浏览，当前项目默认展开；其他项目仅显示目录信息，切换到该项目后才能打开原会话。已关闭会话的回传留在持久 outbox，Host 恢复原会话后写入并确认，防止重复显示。

“接入设置”提供本机检测、配对、连接编辑、协议检查与显式模型测试。高级 MCP 包含入口启停、项目授权列表与撤销、创建并复制授权和无密钥配置模板。密钥只在后端短暂使用，经本机剪贴板复制，不返回浏览器或模型；复制失败撤销新建授权。自动配对强制不调用模型，启动、写入与测试均须用户点相应按钮。

## 上下文与工具

每轮自动读取当前项目的安全上下文：定位、规模、研究重点、任务、已确认决策、风险与轻量案例索引。演示项目的 `isSynthetic` 标记跟随上下文；私密及财务资料遵循既有 ProjectHub 过滤规则。索引用于初筛，全文按需由 `hub_case_details` 深读。

Hub 原生工具包括项目上下文、案例索引与详情、公开检索、公开页面读取、调研归档、案例成果生成、外部协作派单及回传查询。公开检索使用 [Exa 的公开 MCP 服务](https://exa.ai/mcp)，无需另填搜索 Key，服务限额或网络错误明确返回；结果摘要不能代替原始页面核验。归档复用原有公开页面读取、证据核验和实测高清图片服务。

案例命令的本轮只开放这些工具及网页、图片查看和任务列表工具，避免绕去终端扫描 store、写下载或 PPT 脚本。后续普通建模对话恢复原有工具，不全局禁用专业软件能力。模型不支持看图时明确按正文结构与图注筛选，不冒充已经视觉核验。

PPT 接受 ADH 提交的逐页标题、正文、图片 asset ID 和来源；长正文自动续页，不静默截断。分析页从 ADH 已选图片中均衡取两个案例的代表图。原图始终保留完整归档，不因成果只展示少量图而删除。

## 实现与边界

- `backend/dsh-plugins/adh-project-workbench/`：原生会话上下文、工具与输入框 UI、命令和中文工具卡片。
- `backend/adh-workbench-service.cjs`：本机短期凭据桥、项目／会话绑定、案例工具、外部派单及成果登记。
- `backend/adh-collaboration.cjs`：批量任务、目录、进度与成果投递队列。
- `backend/case-web-archive.cjs`、`case-article-ipc.cjs`：本地图文副本与隔离阅读协议。
- `backend/project-research.cjs` 的 `ingestAdhResult`：原生 ADH 研究回写，不建立外部 Job／Run。
- `backend/public-search.cjs`：公开检索；搜索词发送给公开服务，原始本地项目文件不随检索上传。
- `backend/research-presentation.cjs`：按 ADH 逐页方案输出可编辑 PPTX。
- `adh-workbench-ui.js`：案例页到 ADH 的选择和草稿交接。

桥只监听本机，Bearer 凭据仅通过宿主环境传递，不写进客户端、模型上下文或配置文件；原生子进程会剥离 Token 类环境变量。工具不能自行切换外部执行器，必须匹配用户菜单选择。等待派单预检期间切换项目会取消旧任务，避免误派到新项目。成果只能使用当前项目案例的合法图片，保存到本机项目成果目录。

## 验收口径

实际业务验收必须在运行中的 Hub 里选择项目、点击案例／ADH 入口、从原生输入框发送，并观察原生工具调用和成果按钮。命令行生成文件或用假模型烟测不算业务验收。SDK 和后端测试用隔离目录及假网络验证边界，与真实界面验收分别记录。

### 前轮布局回归记录（当前已采用精简输入区）

修复项目栏横铺整页、长成果按钮挤散原生用量栏的问题。项目、快捷任务和成果统一放入 `conversation.input.dock`，复用原生输入卡宽度变量；不再占用原生 `conversation.composer.dock`。仅展示最新「打开 PPT／查看分析页」，旧版本收进历史成果弹窗；执行器名称截断，窄栏自动换行。

真实 Hub 的江湾研究会话已检查宽屏、1024／800 宽度及打开右栏后 380px 聊天输入卡，新增区域均与输入卡对齐，无横向溢出或底栏重叠；执行器、案例选择和历史成果弹窗检查通过。截图保存在 `.smoke-data/adh-ui-repaired-*.png`。原有 13 条案例、4 个成果、15 个外部任务与 15 次运行均保留，本次未发送模型消息或外部任务。

系统「选择打开应用」可能让 `shell.openPath` 长时间等待；现在 1.2 秒内先确认已交给系统，避免聊天请求等待到超时，并将后续失败限定回传给原会话。网络／超时提示统一为中文。后端与原生插件相关回归 25/25 通过，包括挂起、迟到失败、重复点击与会话隔离。

### 本轮真实界面验收

- 主导航已更名「AI Hub」，不再显示独立「Agent 协作」入口、旧页面或旧输入框。在 AI Hub 左侧打开「Agent 协作中心」，任务目录与接入设置均可使用；真实点击「仅检测」返回本机运行时结果，高级 MCP 设置可展开。未为验收新建或撤销项目授权。
- 江湾项目的苏河湾谷德案例已通过实际案例预览补档，正文 64 个项目图片位置全部保存（含 2 个 GIF），本地文章显示 64/64、缺失 0。文章外推荐、广告图未计入项目图；62 张图片取得经尺寸核验的更高分辨率版本。重启后从本机协议重新打开文章和原图成功。
- 从原生输入框一次发送 OpenClaw 与 Hermes 两项不同任务，均生成独立记录。Hermes 成功回传；OpenClaw 首次在网关预检失败，未调用模型。恢复原有本机网关后，在同一对话显式发送一条新的 OpenClaw 验收任务并成功回传。两种 Agent 的结果与失败状态均在原会话实际可见，未重跑旧批次。
- 实际切换执行器：ADH 恢复可选原生模型；外部 Agent 时本栏禁用并提示使用其自身模型。输入框上方常驻项目小字和成果栏已移除。研究与 PPT 原有成果保留，本轮不重复生成。
- 完整本地测试 655 项：646 通过，9 项为原有演示公司初始化与项目隔离同步基线失败；本轮相关原生 SDK、回传、设置、归档与协议测试通过。本地隔离阅读烟测验证 32 张图片响应、图文顺序和脚本阻断；它只验证边界，不代替上述真实操作。
- 最后重启后，实际原生消息卡已显示两个 Agent 的完整回传正文，去掉自有包装中的重复长任务和说明；设置页仍无任务输入框。服务、客户端与已安装 SDK 的最终定向回归 39/39 通过。重启时发现另一项并行技能共享改造先引用尚未落盘的可选模块，已补缺组件时的启动容错，保留其全部接入代码；共享组件不可用时单独提示，不阻止其余 Hub 功能。
