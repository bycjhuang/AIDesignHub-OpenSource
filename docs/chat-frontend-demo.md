# 项目群聊前端 Demo

本次范围：只搭建可交互的项目群聊页面，不建设聊天后端，不接入开源 IM 服务、不迁移已有消息数据。

## 页面入口

- 全局右侧窗口只保留「项目群聊 Demo」与「项目助手」两个入口，不再显示设计决策、业主沟通、模型与图纸频道。
- 项目群聊随当前项目切换；顶部展开按钮可放大聊天窗口。
- 群成员与群设置在右侧展开。角色修改只在 Demo 中展示，不修改团队正式权限。
- 搜索支持演示消息的关键词、成员和文字／图片／文件类型，并可跳回对应消息。
- 支持本窗口内的消息发送、引用、表情、提及、文件卡片、图片预览、拖放与粘贴图片。
- 截图与语音按钮仅展示明确标注的模拟流程，不读取屏幕、不访问麦克风。
- `@DesignHub` 在内存中创建上下文候选；不确定内容先追问。通过候选按钮或引用明确关联补充，普通下一条消息不会误当成答复。
- 候选进入「项目上下文」的独立演示审批区。模拟负责人批准后才显示为「已批准（演示）」；未澄清或退回的候选不会收录。

## 数据边界

`chat-demo-ui.js` 不依赖 `bycjWorkbench`，不调用 IPC、模型、网络或持久化存储。项目名称与成员来自现有工作台只读数据；对话示例为虚构内容。Demo 消息、草稿、附件预览和角色覆盖分别按项目与本机成员保存在页面内存中。刷新／重启即清空，不会向其他成员投递。

本地附件只在用户选择、拖入或粘贴后创建浏览器预览。最多 5 个待发送附件，单文件 12 MB，每项目／成员演示会话累计 40 MB。不解析文件正文，不自动归档。图片使用受限的 `blob:` URL，页面 `connect-src 'none'` 保持不变。

旧频道与旧聊天历史仍保留在原有存储中，没有删除或合并进 Demo。现有项目助手保留真实的模型配置与人工确认写入流程，与群聊 Demo 明确分开；外部执行器仍在 Agent 协作区。

## 助手与项目管理入口

- 项目助手顶部不再显示「成员」和「…」；群成员交互在群聊 Demo 中，正式角色管理在「团队与设置」。
- 模型设置位于助手输入框下方，与「项目上下文」「会话设置」并列。移除每次调用勾选、手动整理与重复记录入口。
- 真实助手首次发送前确认模型服务和本次资料范围。同一窗口、项目、身份、模型和页面范围内无需逐条勾选；切换项目或模型重新确认，关闭窗口不保留授权。会话设置可查看范围或停用。
- 尚未配置模型时，保留输入并打开模型设置，不发送消息或默认为调用外部服务。
- 真实候选可由普通成员提出，但只有当前项目实际有效的项目经理或公司负责人可审批写入。看板关注视角或 Demo 角色不授予审批权限。
- 「项目文件」改为可视化「项目上下文」：基础档案、进度任务、确认沟通与纪要、重要决策、风险、待审批候选和回执。来源文件折叠保留，不根据文件变化自动判定完成率。
- 团队看板显示实际项目身份。仅修改看板关注视角不会获得角色管理权限；演示角色调整也不会修改正式项目角色。
- 普通启动不再自动恢复旧局域网服务器或客户端。历史同步配置原样保留，但不会因历史配置阻止新建或切换项目，不需用户寻找「断开同步」。
- 旧协议仅在显式设置 `AIDESIGNHUB_LEGACY_TEAM_SYNC=1` 的开发运行或历史 smoke 中启用。开启后仍保留真实连接的项目隔离保护。
- 产品方向是加入团队后自动同步授权的项目协作信息；本轮没有建设跨电脑同步服务，也不会自动上传本地项目文件。

## 验证

```powershell
npm test
node scripts/chat-demo-smoke.cjs
node scripts/chat-demo-app-smoke.cjs
node scripts/project-hub-ui-smoke.cjs
```

前端烟测使用独立临时 Electron 配置和合成项目，不读取真实用户数据库；拦截并检查网络、IPC、麦克风、屏幕读取和持久化调用。历史 `global-chat-ui-smoke.cjs` 中的群聊后端发送断言属于之前的真实聊天方案，不是本 Demo 的验收标准。

上一版已验证群聊 Demo、旧同步默认停用与项目隔离。最新审批和上下文改动需运行上述命令验证，以实际测试输出为准；不要沿用旧测试数量当作新版本验收结果。

完整窗口回归另外预置了合成的旧客户端配置：验证它不会激活同步或阻止操作；通过真实界面创建并进入新项目后，顶栏和群聊随之更新，原项目与原消息保留、新项目不复制旧消息、历史连接配置不被删除。助手输入框下方的模型设置也已实际打开原配置弹窗。所有测试均未调用模型或使用真实用户项目。

- 实际助手审批 UI 使用临时数据验证：设计师只读候选、越权 IPC 被拒；切换真实项目经理后可审批，写入与审计成功。没有修改使用者身份或真实数据。
- 「查看审批」会先收起聊天窗口再跳转项目上下文，避免审批内容被遮挡。
- 未调用真实模型，未建设跨端群聊、审批推送或企业身份认证。真实助手追问质量仍需配置模型后验证。
