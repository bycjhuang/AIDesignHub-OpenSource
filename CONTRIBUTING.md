# Contributing to AIDesignHub

Please discuss substantial changes in an issue first. Include focused changes,
their purpose and relevant validation. Never submit user projects, credentials,
private skills, customer material or another person's work without permission.

Original code contributions are submitted under AGPL-3.0-only, with copyright
retained by their authors. Identify imported components and keep all applicable
licenses, copyright notices, source links and modification notices. Check that
you are authorized to contribute employer-owned work before submitting it.

Use a `Signed-off-by: Your Name <your email>` line to certify the contribution's
origin under Developer Certificate of Origin 1.1:
https://developercertificate.org/ . DCO is an origin certification, not a
copyright transfer or an automatic grant to relicense contributions commercially.

Any future alternative proprietary/commercial license must cover only material
whose rights permit it. Community contributions cannot be placed under such a
license without sufficient separate permission. No CLA signing workflow or
blanket contributor relicensing grant is represented as already in place.

Run `npm run audit:licenses`, relevant tests and `npm test` before a release.
The source release must include build scripts and dependency lockfiles. A
downloadable binary and its matching source must identify the same release.

UI text and documentation should describe current, verified capabilities.
Local model tests must use fixtures unless a real paid request is specifically
authorized. See AGENTS.md for the renderer/preload boundary and project workflow.
