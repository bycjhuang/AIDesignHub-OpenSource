# AIDesignHub 当前状态（单入口）

> 更新：2026-10-29 ｜ 维护规则：每次改造完成后更新本文件「当前版本状态」；历史细节留在 `docs/` 带日期的文档里。
> 用法：新会话 / 新接手的人先读本文件，再按「文档导航」按需展开，不必通读全部文档。

## 一句话

Windows 本地工作台（Electron + 本地后端），把设计项目的任务、决策、风险、上下文和外部 Agent 协作集中管理起来——人主导，AI 辅助记录，不替代审批。

## 架构速览

```
electron-main.cjs（主进程：窗口 / IPC / 系统能力）
   └─ preload.cjs（受限 IPC 桥，白名单）
        └─ index.html + *-ui.js + app-v2.js（渲染层，无 Node 权限）
             ↕ IPC
        backend/*.cjs（本地后端：持久化 / 知识 / 聊天 / Agent / 模型）
```

- 渲染层按 `index.html` 顺序加载：`error-monitor.js` → 各 `*-ui.js` → `app-v2.js` → `setup-center-ui.js`
- 数据保存在当前 Windows 用户的应用数据目录；模型密钥加密在 `device-settings-v1/model-private/`
