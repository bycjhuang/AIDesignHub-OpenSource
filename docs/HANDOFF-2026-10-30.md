## 接手开发和发布

换机从公开仓库 `main` 克隆，安装 Node.js 22.12+（建议 24）后运行 `npm ci`。画布需要单独安装其锁定依赖并构建：

```powershell
npm ci
cd Loomic-main/Loomic-main
corepack pnpm install --frozen-lockfile
cd ../..
npm run build:ai-design
npm start -- --demo-company
```

ADH、专业 MCP 与离线知识引擎运行资源不在 Git 中，按 [公开构建说明](open-source-build.md) 和 [安装包说明](local-release.md) 从同版公开安装负载或明确来源准备。只克隆源码不等于这些运行组件已就绪。真实用户数据、知识索引、附件、模型密钥和外部 Agent 配对不会随 Git 自动搬家；新电脑通过程序设置自己的模型和本机连接。

本机网页构建与预览命令：

```powershell
python scripts/cache-public-demo-assets.py
node scripts/build-public-demo.cjs
node scripts/preview-public-demo.cjs
```

产物位于 `.runtime/website-demo-20261030/dist/`，预览地址为 `http://127.0.0.1:8799`。构建前需准备同版 Loomic 输出和 Harness 公开运行资源。视频源来自维护机桌面成片目录，先运行 `python scripts/publish-public-intro.py prepare` 才能在本机预览完整视频；元数据和封面入 Git，大体积 MP4 不入 Git。本地预览不发送真实注册邮件、不接受真实账号登录。

网站维护先执行只读命令：

```powershell
python scripts/deploy-public-demo.py status
```

部署脚本依赖维护机已有的 BYCJ 部署配置、SSH 凭据与可信主机记录；公开源码不携带这些凭据，换机必须另外配置。需要发布时，依次构建、`stage --apply`、核对回执，再 `activate --apply`，保留旧版。回退使用 `python scripts/deploy-public-demo.py rollback --apply`，只退当前记录的上一版；当前上一版是 `e8764db146d1`，不会直接跳到无视频版。执行前重新查询状态，防止其他会话已发布更新。
